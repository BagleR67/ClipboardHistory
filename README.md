# ClipboardHistory

## Приложение, позволяющее Вам увидеть историю вашего буфера обмена.

#### Вас тоже раздражает, что если вы случайно скопируете что-то новое, то старое содержимое буфера обмена пропадает?
Это приложение позволяет просматривать историю копирований. Вы можете в любой момент открыть приложение из трея и скопировать какую-то старую информацию, чтобы не копировать ее из первоисточника заново.
